## 📖 О проекте
Адаптивный сайт, посвященный путешествиям. В проекте реализована адаптивная вёрстка под мобильные устройства, планшеты и десктопы, интерактивные элементы и работа с формами.

## 🛠 Стек технологий
- **Разметка:** HTML5 (семантическая верстка, доступность)
- **Стилизация:** SCSS (методология БЭМ, flexbox, grid, адаптивность)
- **Скрипты:** JavaScript (ES6+, работа с DOM, интерактивные элементы)
- **Сборка:** Gulp 5 (оптимизация графики, сборка спрайтов, линтинг)
- **Инструменты:** Git, npm, Stylelint, ESLint, Linthtml
